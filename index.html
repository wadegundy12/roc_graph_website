MAKE IT CLICK

“True” means correct.

“Positive” means the model predicted the class of interest. A false positive is a positive prediction that is wrong. A false negative is a negative prediction that is wrong. Positive does not mean “good.”

Two pairs sum to one.

Every actual positive is either caught or missed. Every actual negative is either rejected or falsely flagged. Each pair uses the same denominator.

TPR + FNR = 1
TNR + FPR = 1

Precision ≠ recall.

Recall starts with actual positives. Precision starts with predicted positives. Catching every positive can give perfect recall while still producing many false alarms.

What does AUC tell me?

AUC is the area under the entire ROC curve, computed here by adding trapezoid areas between adjacent points. It is also the probability that a randomly chosen positive receives a higher score than a randomly chosen negative, giving half credit for ties. Perfect separation gives 1.00; chance-level ranking gives 0.50. The top-left corner, (0, 1), means no false alarms and all positives caught.

Moving the threshold changes your operating point, not the model’s AUC. Try the different model rankings to change the curve itself. AUC below 0.50 suggests reversed ranking; it is not a negative area.

Why do I sometimes see “—” instead of a rate?

A fraction with a zero denominator is undefined. If no examples are predicted positive, precision has no denominator. If none are predicted negative, NPV is undefined. This lab shows “—” rather than pretending that rate is zero. TPR and FNR require actual positives; TNR and FPR require actual negatives. All included datasets contain both classes.

Which threshold should I choose?

There is no universally best threshold. Lowering it can reduce missed positives while increasing false alarms. Choose using the relative costs of these errors and validation data, then evaluate on held-out test data. A threshold of 0.50 is a convention, not a guarantee of the best decision.

What about imbalanced classes?

Accuracy can hide poor detection: predicting “negative” for every example in a dataset with 99% negatives gives 99% accuracy and zero recall. Precision depends on class prevalence. For fixed class-conditional score distributions, ROC rates do not directly depend on the class proportions, but many false alarms can still overwhelm a rare positive class. A precision–recall curve is often useful alongside ROC in that setting.
